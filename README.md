# pairwise-portal-teleport

角色从传送门出来时被弹回原地，出口变换把入口的相对坐标直接当成世界坐标用了；两扇门互相可见时，相机穿过第一扇后没有切换到第二扇的视图，看到的还是传送门前画面；角色带着速度穿门，速度方向没随门的朝向旋转，出来时横着飞；门的朝向相差 180 度时四元数取反，角色被翻转成头朝下；穿门瞬间的碰撞检测仍在入口空间做，角色卡在门框里；传送后相机跟随的插值在旧位置与新位置之间拉了一条长线，画面瞬移；物体被门裁剪时只裁了一侧，从背后看门是空心的；多层传送时门中门递归超过两层就死循环，没有深度限制；网络同步时传送被当成普通位移，客户端插值把角色拖回入口；重力方向没随门旋转，从竖门出来角色贴着墙走。gameplay/portal_teleport.py 是核心，tests/test_portal_teleport.py 15个红。要修的是：局部到世界矩阵链；递归视图切换；速度随门旋转；四元数连续；传送前后碰撞空间；相机瞬移不插值；双面裁剪；递归深度上限；传送走瞬移同步；重力随门变换。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
